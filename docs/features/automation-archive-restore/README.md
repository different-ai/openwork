# Restore archived Automations

`automationArchiveRestore` is off by default on cloud and self-hosted. Owner: `benjaminshafii`.

Enable the feature for a test organization. Archive an Automation with a run, open **Archived** from the Automations list, and select the Automation. **Restore** returns it to the main list without resuming its schedule. Its run history stays available. Try this in both the desktop app and Den.

Turning the feature off hides the archive list and Restore action. Restored Automations and their run history are unaffected.
