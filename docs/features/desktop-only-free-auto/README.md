# Desktop-only free models

Roll out the gateway and a proof-capable desktop first. Enable the feature for a test organization, then across the deployment to include guests. A supported desktop responds to the gateway challenge using an OS-protected installation key and release tag. The challenge is HTTP 426 `desktop_update_required` with `desktopProof: "required"`, so released desktops that cannot sign show an update prompt. Set `DESKTOP_FREE_MIN_VERSION` to the first proof-capable release so the prompt names it. OpenWork Web and other servers without the desktop signer report free models as desktop-only. Each proof covers the request and expires within the replay window. Both guest and member exchanges require the gateway token secret, accounting identity key and release verification key. Hosted Workbot keeps free Luna when Den and every gateway share `WORKBOT_FREE_GRANT_SECRET` (at least 32 characters, distinct from the other Free Auto secrets): Den signs a two-hour grant bound to the member's key and organization, and the gateway accepts it in place of desktop proof. Without that secret, hosted callers need a paid model or a configured provider. A shared release tag can be recovered from a distributed binary. The protocol raises the cost of casual API use and does not provide hardware attestation.
