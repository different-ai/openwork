# Computer suggestions in chat mentions

`composerComputerMentions` · cloud and self-hosted · owner: `benjaminshafii`.

Leave this off while execution-target mentions are deferred. Typing `@` still offers files and agents, and task references where inline suggestions are enabled. Other execution-target selectors and existing chat history are unaffected.

To check the switch, open a fresh chat and type `@`. With it off, no Cloud or Desktop run-target option appears. Turning it on restores the existing suggestions; it does not add a new syntax or change routing. Turning it off again does not rewrite messages or drafts.
