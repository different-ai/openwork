# Search from the browser address bar

Turn on **Search from the browser address bar** for a desktop member or organization to try it. In a built-in browser tab, enter a search and press Enter. The tab opens Google results using the normal website permissions. A website address opens directly. Escape discards the edit and restores the current address.

Only submitting a search sends it to Google. OpenWork does not request suggestions as the person types. Turning the feature off restores the address-only field.
