# Den dashboard organization branding

`denOrgBranding` · cloud and self-hosted · owner: `benjaminshafii` · off by default.

Enable this for an organization that has configured Brand Appearance. Its Den dashboard sidebar shows the wordmark, or the square icon and app name, and the browser tab shows the configured app name. If the wordmark fails, the sidebar tries the icon and name. With no branding, the existing OpenWork mark and title remain.

Turning the flag off restores the previous sidebar and title without changing saved settings, favicon behavior, desktop branding, or sign-in.
