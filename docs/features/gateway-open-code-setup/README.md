# AI Gateway: OpenCode setup

- **Feature key:** `gatewayOpenCodeSetup`
- **Deployments:** cloud and self-hosted, off by default
- **Author:** benjaminshafii
- **Public docs:** [OpenCode plugin](../../../packages/docs/model-context-protocol/opencode-plugin.mdx)

In **My Library › Models › Set up**, choose **OpenCode**. The dialog shows how to install `opencode-openwork` in OpenCode 2 and sign in through the browser. There is no manual API key to create or copy. The existing plugin loads the organization's available models and MCP connections after approval. The guide covers configuring a self-hosted API URL.

The setup row is in the existing third-party tool section. To try it, enable **Allow 3rd party tools & harnesses** and turn on `gatewayOpenCodeSetup` for the test organization.

Turning off the feature hides the setup button. It does not uninstall the plugin or end existing sessions.
