## 保留的不可译元素

- **语法高亮语言名**（约 130 个）：typescript、rust、python 等（编辑器着色引擎内部名称）
- **组件内部名**：Combobox、Select、Accordion、Toast 等
- **快捷键 meta**：`Cmd/Ctrl+*` 等（保持跨平台一致）
- **KaTeX 库内部选项**：LaTeX 渲染库的选项名
- **语言选择器 label**：界面渲染使用 `t.nativeName`（如 "中文（简体）"），`label` 字段不显示，无需翻译
- **用户工作区名称**：如 "OpenWork Chat" 是用户命名，非 UI 文案
