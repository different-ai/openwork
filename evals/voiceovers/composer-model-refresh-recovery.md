# composer-model-refresh-recovery — Assigned models appear without restarting

1. OpenWork is running with managed model access, but this user has no organization models assigned. The composer shows one compact, single-line notice with a clear Retry action.

2. An administrator assigns GPT-5.4 while the app remains open. The user clicks anywhere on the notice to retry organization model discovery; the empty-state notice disappears, GPT-5.4 is selected, and the composer is ready without closing or restarting OpenWork.
