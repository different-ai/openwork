# composer-prompt-controls — Prompt controls use one accessible component language

1. I open the agent selector from the prompt. It uses the same focused select surface as the rest of OpenWork, keeps the current agent visible, and offers the default and available agents with native keyboard navigation.

2. I open the tools browser from the prompt toolbar. It mounts directly above the editor at the full composer width in both new tasks and active conversations. A quiet divider separates it from the prompt, while its compact, top-aligned categories stay visible and only the selected category’s details scroll.

3. I open one model settings menu. It summarizes the selected model and effort in the trigger, then presents Model and the model’s own reasoning setting as clear suboptions instead of splitting them across separate controls.

4. I open the reasoning submenu. Its choices use the same native menu typography as Model, and the current effort is marked with the standard radio check.

5. I open Model from the same menu and type a query. Search filters the provider-grouped models while selected-model state and access to all models remain available in a focused submenu that stays inside the window.
