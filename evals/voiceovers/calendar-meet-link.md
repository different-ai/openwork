# calendar-meet-link — Google Calendar events can include Meet links

1. I ask Micx to schedule a Google Calendar meeting and include a Google Meet link. Micx uses the connected Google Workspace account instead of sending me to Calendar manually.

2. The event is created with the right title, attendee, and time, and Micx confirms both the calendar event link and the Google Meet link.

3. If an event already exists without conferencing, I ask Micx to add a Meet link. Micx updates the existing event instead of creating a duplicate.

4. Micx confirms the updated event now has a Google Meet link, so the invite is ready to send or join without any manual Calendar edits.
