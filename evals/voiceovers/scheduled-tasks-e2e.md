# Scheduled Tasks — review and run one bounded task

1. I open Scheduled Tasks inside this workspace and see a clear local-running boundary, so I know OpenWork—not the chat screen—owns the task and its history.

2. I create a manual task with a self-contained prompt. OpenWork saves it as a disabled draft, giving me something useful to review without granting unattended authority.

3. I review the exact workspace, model, file permissions, runtime limit, and denied action classes before approving this revision.

4. I choose Run once. OpenWork starts the reviewed task in a fresh linked session while the task page shows its live status independently from the conversation UI.

5. When the run completes, I can inspect the durable receipt, open the fresh session, and retrieve the produced workspace file from the task history.
