# marketplace-catalog-legibility — A catalogue you can actually read

1. Here are the organization's marketplaces. Each one shows its own logo, or its initial when it has no logo, the plugin counts line up in a single column so I can compare them at a glance, and the catalogues that actually have something in them come first.

2. A marketplace nobody has filled yet is not a gap in the page. It sits in the same column as everything else, showing a greyed zero, so I can see which catalogues still need work.

3. Opening a marketplace keeps the same identity tile and the same list. Every plugin shows how many components it carries, so I can tell the substantial plugins from the thin ones without opening any of them.

4. Everything here runs in the cloud, so a badge announcing that would be true of every row and would tell me nothing. Instead the page stays quiet, and speaks up only when a plugin needs a connection before my members can use it.

5. The plugins directory is the same list again, and the tabs now carry their counts, so I can see that there are no agents and no commands here without clicking into each tab to find out.

6. And opening a plugin shows me the same tile I clicked on, with the marketplace it came from and when it last changed on one quiet line, so the page starts with the plugin rather than with a slab of colour.
