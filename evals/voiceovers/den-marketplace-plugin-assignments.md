# den-marketplace-plugin-assignments — Manage Marketplaces from a Plugin

1. I open a Plugin, switch to its Marketplaces tab, and use the same compact add pattern as Marketplace member access to find an eligible Marketplace.

2. I add the Marketplace, and the assignment appears immediately on the Plugin while the real resolved Marketplace now contains this Plugin.

3. I remove the Marketplace from the Plugin, and the confirmation makes the boundary explicit: only this relationship is removed while both global resources remain available.

4. I confirm removal, and the Plugin becomes unassigned again while the still-active Marketplace returns to the add picker.
