# den-marketplace-plugin-assignments — Manage Plugin assignments from a Marketplace

1. I open an empty Marketplace as an administrator and choose an existing active Plugin that is not assigned to it yet.

2. I assign the Plugin, and it appears in this Marketplace immediately while disappearing from the eligible assignment choices.

3. I choose Remove, and the confirmation makes the boundary explicit: only this Marketplace relationship will be removed, while the global Plugin and its configuration stay available.

4. I confirm removal, and the Marketplace becomes empty again while the still-active Plugin returns as an eligible assignment choice.
