# workspace-client-primitive — One workspace server connection across Micx

1. Micx opens the selected workspace and shows its session surface with the server connected and ready.

2. The user creates and opens a session in that workspace, and it appears through the same workspace-backed session list.

3. Workspace settings, connections, and extensions load through the selected workspace server without switching endpoints or losing authentication.

4. After the client reloads, Micx reconnects to the same workspace and restores its session and settings state.
