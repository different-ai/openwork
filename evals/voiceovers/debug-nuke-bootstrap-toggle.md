# debug-nuke-bootstrap-toggle — Opt in to deleting organization bootstrap

1. The fresh-start dialog leaves the organization bootstrap alone unless you ask for it. The checkbox starts unchecked and the exact desktop-bootstrap.json path sits under Will survive, so the safe choice is the default one.

2. Tick the box and the bootstrap joins everything else on the chopping block. The path moves into Will delete and disappears from Will survive, while the typed NUKE confirmation is still required.
