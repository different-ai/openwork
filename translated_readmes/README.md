# OpenWork README Languages

Available: [English](../README.md), [简体中文](./README_ZH.md), [繁體中文](./README_ZH_hk.md), [日本語](./README_JA.md)

## Help translate OpenWork

We welcome translations into your native language.

### README translations

To add a README language:

1. Copy `README.md` to `translated_readmes/README_<LANG>.md`.
2. Translate the content.
3. Add the language link to the list above.
4. Add the language to the "Read this in" line near the top of the root `README.md`.
5. Open a PR.

### App UI translations (i18n)

App UI strings live in `apps/app/src/i18n/locales/`, one file per locale.

If you are unsure where to start, open an issue and mention the language you want to contribute.
