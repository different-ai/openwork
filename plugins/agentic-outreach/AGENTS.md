# agentic-outreach/
> L2 | 父级: ../../AGENTS.md

Agentic Outreach 是可安装的 B2B 外联编排插件。它只维护证据、资格、预算、审批与运行状态；实时数据、联系方式购买、发送和回复同步全部通过运行时发现的外部能力完成。

## 成员清单

- `.claude-plugin/plugin.json`: Claude-compatible 插件清单，声明可安装的 Skill、命令与专用 Agent。
- `README.md`: 产品价值、安装方式、运行产物和安全边界。
- `CONTEXT.md`: Outreach 领域语言，统一 Lead、Evidence、Approval、Run 与 Handoff 的业务含义。
- `OPEN_SOURCE.md`: 2026 活跃开源组件、许可证、商业边界和持续刷新决策。
- `ORIGAMI_BENCHMARK_2026.md`: Origami 官方数据链、Agent/API 接入、法律边界与 OpenWork 商业差距的 2026 决策基准。
- `skills/agentic-outreach/SKILL.md`: 核心深 Module；规定能力发现、阶段门、账本、幂等与外联文案协议。
- `commands/outreach.md`: `/outreach` 用户入口，把请求交给核心 Skill 执行或续跑。
- `agents/outreach-operator.md`: 专用执行人格，强化证据优先、禁止猜参和双审批约束。
