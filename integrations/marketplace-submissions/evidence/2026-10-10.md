base control was unavailable; actual deployed result shapes supplied the control.

   suffix on `name` and the original title. Fixed the preflight to select the

2. `2026-10-10T06:17:30.918Z`, exit 1: **“Review fixture content differs.”**
   Inspection showed canonicalized name/quoted description in frontmatter and a
   trimmed final newline; the instruction body was unchanged. Fixed comparison
   to check the exact trimmed body rather than generated frontmatter; no server
   change.
3. The same workspace/fixture was then reused without another provisioning or
