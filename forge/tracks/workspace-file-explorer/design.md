## Key Design Decisions

### 1. 二级切换设计

- 在工作区展开区域顶部添加 `[Sessions] [Files]` 切换按钮
- 默认选中 Sessions（保持现有行为）
- 切换状态按工作区隔离（每个工作区独立记忆）

### 2. 文件树懒加载

- 初始只加载第一层目录
- 点击目录展开时才加载子目录
- 使用展开状态缓存避免重复加载

### 3. 文件预览策略

- 点击文件时异步加载内容
- 使用 Monaco Editor 的只读模式
- 大文件（>100KB）显示警告，>1MB 拒绝加载
- 二进制文件显示"不支持预览"占位符

### 4. 状态管理

```typescript
// 按工作区隔离的状态
{
  // 二级标签状态
  "workspace-id-1": {
    secondaryTab: "files",
    expandedPaths: ["/src", "/src/components"],
    selectedFile: "/src/app.tsx"
  },
  "workspace-id-2": {
    secondaryTab: "sessions",
    expandedPaths: [],
    selectedFile: undefined
  }
}
```

### 5. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 目录读取失败 | 显示错误图标 + 提示 |
| 文件读取失败 | Toast 提示 |
| 文件过大 | 显示警告信息 |
| 二进制文件 | 显示不支持提示 |
| 路径越界 | 拒绝访问 |

## Data Flow

### 文件树加载流程

```
1. 用户点击 [Files] 切换
   │
   ▼
2. Dashboard 调用 fs_read_dir(workspace_root)
   │
   ▼
3. Tauri 后端读取目录，返回 FileEntry[]
   - 过滤隐藏文件（.git, node_modules 等）
   - 标记目录/文件类型
   │
   ▼
4. FileTree 组件渲染
   - 目录可展开/收起
   - 文件可点击
```

### 文件预览流程

```
1. 用户点击文件
   │
   ▼
2. FileTree 调用 onSelectFile(path)
   │
   ▼
3. Dashboard 调用 fs_read_file(path)
   │
   ▼
4. Tauri 后端:
   - 检查路径权限
   - 检测文件类型
   - 读取内容（限制大小）
   - 返回 FileReadResult
   │
   ▼
5. FilePreview 组件渲染
   - Monaco Editor 只读模式
   - 语法高亮
```

```

├── WorkspaceList

│       ├── SecondaryTabSwitch [Sessions|Files]
│       ├── SessionList (现有)
│       └── FileTree (新增)
│           └── FileTreeItem

│               └── File (可点击)
└── MainContent
    └── FilePreview (新增)
        └── MonacoEditor (readonly)
```

## Performance Considerations

1. **虚拟滚动**：大目录使用虚拟滚动（>1000 文件）
2. **防抖加载**：快速切换文件时防抖
3. **缓存**：已加载的目录结构缓存
4. **取消请求**：切换文件时取消未完成的加载
