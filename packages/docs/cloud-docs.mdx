title: "Cloud docs"
---

In order to access Openwork Cloud, you should have an active subscription at [app.openworklabs.com](https://app.openworklabs.com/). 

Openwork Cloud intended for teams that want to share `SKILLs.md`, `MCPs`, `configs`, `agents` and sandboxed workers. 
Once you have an organization setup, you can also test the [Cloud API](/api-reference).

If you meant to check the documentation for the desktop app, you can do it here at [desktop docs](/get-started) instead.
