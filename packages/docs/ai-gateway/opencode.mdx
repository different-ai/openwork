With an [AI Gateway API key](/ai-gateway/third-party-tools) you can run
[OpenCode](https://opencode.ai) on the models your organization gives you.
Requests go through AI Gateway like any other: the key only reaches models
you're allowed, and usage counts toward your limit.

OpenCode talks to AI Gateway through its OpenAI compatible endpoint, so every
model works, whatever its provider: Claude, GPT, Gemini and the rest.

## Set it up

Create a key in **My Library › Models** and pick **OpenCode** under **Set up**.
The steps there fill in your key and your models for you.

1. **Put the key in your shell profile.** Add this line to `~/.zshrc` (or
   `~/.bashrc`), then open a new terminal:

   ```bash
   export OPENWORK_API_KEY="<your API key>"
   ```

2. **Add the provider to OpenCode.** Save this as `opencode.json` in your
   project, or as `~/.config/opencode/opencode.json` for every project. If you
   already have one, merge the `openwork` provider into it:

   ```json
   {
     "$schema": "https://opencode.ai/config.json",
     "provider": {
       "openwork": {
         "npm": "@ai-sdk/openai-compatible",
         "name": "OpenWork",
         "options": {
           "baseURL": "<OpenAI base URL>",
           "apiKey": "{env:OPENWORK_API_KEY}"
         },
         "models": {
           "<model id>": { "name": "Claude Sonnet" }
         }
       }
     },
     "model": "openwork/<model id>"
   }
   ```

   The **OpenAI base URL** and each **model id** are under **Use OpenWork AI
   Gateway with other tools** in **My Library › Models**.

3. **Start OpenCode** in your project with `opencode`. **/models** lists your
   OpenWork models under **OpenWork**.

[Smart Routers](/ai-gateway/auto-model-routing) work too: add one by its id,
`openwork-smart-<router id>`, like any other model.

## When it doesn't work

- **`401 invalid_api_key`**: the key was revoked, has expired, or 3rd party
  tools are turned off for your organization. Check it in **My Library ›
  Models**.
- **A model is missing from /models**: add its id under `models` in
  `opencode.json`. Models your organization adds later aren't listed until you
  do.
