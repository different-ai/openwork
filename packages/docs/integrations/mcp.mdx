Add one URL to any MCP client to use your organization's skills, plugins, workflows, and connected tools.

```text
https://api.openworklabs.com/mcp/agent
```

Sign in with your OpenWork account in the browser and pick your organization. The agent gets what's assigned to you.

## How it works across clients

1. An admin shares skills and service connections with people or teams in OpenWork.
2. Each person adds the same gateway URL to their preferred MCP client and signs in.
3. The agent uses `search_capabilities` to find an authorized capability and `execute_capability` to use it. It can also use `list_skills` and `get_skill` to retrieve skill instructions. Clients that support the [MCP Skills extension](https://modelcontextprotocol.io/seps/2640-skills-extension) discover the same skills on their own through `skills/list`.
4. OpenWork applies the member's access grants and connection tool settings to requests through the gateway.

Your team sets things up once, instead of copying MCP settings and skills into every client.

## Models and specialized plugins

MCP adds tools and skills; your client keeps its own model provider. To use your organization's AI Gateway models too, use a [client plugin](/integrations/client-plugins).

The [OpenCode plugin](/model-context-protocol/opencode-plugin) is ready. Cursor and Codex plugins are in progress; MCP works in both today.
