OpenWork Connect is an AI Gateway, MCP Gateway, and Skills Gateway that lets organizations centrally manage models, tools, reusable skills, and access from one admin panel.

Use them from the AI client you already have. The OpenWork desktop app is optional.

## What each gateway provides

| Gateway | What your organization manages | How your client uses it |
| --- | --- | --- |
| AI Gateway | Approved models, provider credentials, usage, and supported spend limits | Model requests go through the AI Gateway |
| MCP Gateway | Shared service connections and tool access | Your agent discovers and calls authorized tools |
| Skills Gateway | Reusable skills assigned to people and teams | Your agent retrieves the skills it can use through OpenWork MCP |

MCP carries tools and skills, not model calls. The OpenCode plugin connects both with one sign-in. In other clients, models come from an AI Gateway API key.

Cursor, Codex, Claude Code and other OpenAI or Anthropic compatible tools can already use your organization's AI Gateway models with an [AI Gateway API key](/ai-gateway/third-party-tools). That is a separate setup from MCP.

Every integration uses the signed-in person's access. Installing one doesn't grant anything extra.

## Services OpenWork connects to

Most apps reach OpenWork through MCP. Google Workspace and Microsoft 365 are built in, with no MCP server, and we build more on request for enterprise customers. See [Native integrations](/integrations/native-integrations).
