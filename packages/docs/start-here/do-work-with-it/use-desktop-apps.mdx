---
title: Use desktop apps
description: Let your agent work in Mac apps.
---

Computer use lets the agent read and control Mac apps when the feature is enabled for your organization. Ask for the task in chat; OpenWork opens the app and selects its window automatically.

## Set up your Mac

Use macOS 14 or later. If macOS permissions are missing, OpenWork shows a setup checklist. Turn on Accessibility and Screen Recording for the app named in that checklist. These are macOS system permissions; there are no additional chat or window approval prompts.

## Watch and take over

The Computer view shows the app window and the agent's activity. Use **Take over** to pause input, **Continue** to hand control back, or **Stop** to end the current task. A new message can start another task without asking for access again.

Only the selected app window is captured. Its content may be sent to your selected model provider. Turning the computer-use feature off ends active computer work.
