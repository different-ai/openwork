---
title: "Control the browser"
description: "How to use Micx to automate the built-in browser"
---

Computer-use in Micx currently works through the built-in Micx Browser. It does not yet mean full desktop control of Ubuntu, macOS, or Windows apps.

Micx can open pages, click, fill forms, read page content, and take screenshots inside that browser. If you connect to a remote Micx server, the browser runs on that remote worker.

Today, the supported path is the first-party `Micx Browser` extension.

## Requirements

- Use the desktop app or a remote worker that exposes the Micx Browser.
- Keep `Micx Browser` enabled in `Settings > Extensions`.

Then go back to the session view and ask Micx to open a website.
