Can't find what you're looking for? There are two ways to fix it.

## Ask us to write it

[Email the team](mailto:team@openworklabs.com?subject=missing%20documentation&body=hey%20my%20github%20is%20%7Busername%7D%2C%20I%27m%20interested%20in%20%7Bfeature%7D%20from%20openwork%20but%20I%27m%20missing%20documentation%20on%20it%2C%20could%20you%20create%20it%3F%0A%0AThanks). Tell us which feature you're trying to use, and we'll write the page.

## Write it yourself

The OpenWork docs live in the [openwork repo](https://github.com/different-ai/openwork/tree/dev/packages/docs). Add a new `.mdx` page, open a pull request, and we'll review it.
