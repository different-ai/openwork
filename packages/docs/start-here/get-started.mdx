## Share it with your whole org

Build a skill once. Everyone who should have it gets it, without editing JSON.

- **Marketplaces for skills, plugins, and MCPs.** Publish once, then assign to the org, a team, or one person. See [Collections](/cloud/share-with-your-team/collections).
- **Loaded just in time.** The MCP Gateway exposes two tools, `search_capabilities` and `execute_capability`, so agents find what they need instead of loading every tool up front.
- **Advanced RBAC.** Default and custom roles, plus team-based access. See [Members and RBAC](/cloud/members-and-rbac).
- **SSO and SCIM.** Okta, Microsoft Entra, and Google Workspace.
- **Desktop policies.** Control what the desktop app allows per org, team, or member. See [Desktop policies](/cloud/share-with-your-team/desktop-policies).
- **Audit log and spend observability.**

Run it on OpenWork Cloud or [self-host it](/start-here/self-host). The price is the same either way. SSO, SCIM, RBAC, desktop policies, and the audit log are on the Enterprise plan. See [Pricing and licensing](/start-here/pricing-and-licensing).

## Get started in four steps

<Steps>
  <Step title="Install OpenWork">
    [Download the desktop app](https://openworklabs.com/download) for macOS, Windows, or Linux. Every release is also listed on [Downloads](/start-here/downloads).
  </Step>
  <Step title="Pick a folder">
    Choose the folder you want to work in. OpenWork only works with folders you authorize, and you can add more later in settings.
  </Step>
  <Step title="Choose a model">
    [Sign in with ChatGPT](/start-here/connect-your-stack/sign-in-with-chatgpt), add an API key such as [Anthropic](/start-here/connect-your-stack/add-anthropic-api-key), or [run a local model](/start-here/connect-your-stack/use-local-models) with Ollama or LM Studio.
  </Step>
  <Step title="Run your first task">
    Ask OpenWork to summarize the folder before changing anything. It confirms OpenWork can read the files you expect.
  </Step>
</Steps>

Moving from Claude Cowork? Follow [Migrate from Claude Cowork](/start-here/migrate-from-claude-cowork).
