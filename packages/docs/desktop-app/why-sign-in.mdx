---
title: "Why sign in?"
description: "What the OpenWork desktop app does without an account, and what signing in to OpenWork Cloud adds."
---

Signing in is optional. To sign in, open `Settings > Account` and click `Sign in`.

| Works signed out | Needs an OpenWork Cloud sign-in |
| --- | --- |
| Chat with your files in authorized folders | [Connections](/start-here/connect-your-stack/connect-services) your org shares, such as Gmail or Slack |
| [Your own models](/start-here/connect-your-stack/add-a-custom-llm), API keys, [ChatGPT sign-in](/start-here/connect-your-stack/sign-in-with-chatgpt), or [local models](/start-here/connect-your-stack/use-local-models) | [OpenWork inference](/start-here/connect-your-stack/openwork-vs-opencode-models) models |
| Local workspace skills | Adding skills and plugins from `Settings > Library`, team-shared skills, and [sharing your own](/start-here/do-work-with-it/publish-and-copy-a-skill) |
| [Custom MCP servers](/start-here/connect-your-stack/add-an-mcp-server) in a workspace | Automations |
| | [Dashboards](/dashboards/overview) and saved apps |
| | Cloud workspaces that keep tasks running while your computer sleeps |

Signing in to ChatGPT or another model provider is separate from signing in to OpenWork Cloud.
