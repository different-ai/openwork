description: "Install the OpenWork desktop app, pick a folder and a model, and run a first task. No sign-in needed."
---

<Steps>
  <Step title="Install">
    [Download OpenWork](/start-here/downloads) for macOS, Windows, or Linux.
  </Step>
  <Step title="Pick a folder">
    OpenWork only works in folders you authorize.
  </Step>
  <Step title="Choose a model">
    [Sign in with ChatGPT](/start-here/connect-your-stack/sign-in-with-chatgpt), [add an API key](/start-here/connect-your-stack/add-anthropic-api-key), or [run a local model](/start-here/connect-your-stack/use-local-models).
  </Step>
  <Step title="Run a task">
    Start with "Summarize this folder."
  </Step>
</Steps>

Next: [connect services](/start-here/connect-your-stack/connect-services), [create a skill from chat](/start-here/do-work-with-it/create-a-skill-from-chat), or read [why sign in](/desktop-app/why-sign-in).
