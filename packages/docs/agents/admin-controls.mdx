<Warning>
Agents are in private alpha. OpenWork does not officially support this feature yet, and how it works may change. To try it, ask your OpenWork contact to turn it on for your organization.
</Warning>

In the [OpenWork Cloud dashboard](https://app.openworklabs.com), open **Agents** under **Manage**. The list shows up to 200 of the newest agents. It doesn't show archived agents. Members create agents in the desktop app.

![The Agents page in the dashboard: three agents, the settings for every agent, and two tool rules](/images/agents/admin-agents.png)

## Read the list

| Column | What it shows |
| --- | --- |
| **Agent** | The agent's name and whether an admin paused it. |
| **Owner** | The member who owns it. |
| **Access** | Who can use it. **Not shared** means it's private. |
| **Can change things** | Counts the agent's own tool settings and any connections it blocks. It doesn't count defaults or organization rules. |
| **This month** | What the agent has spent this month and its budget, if set. |
| **Last run** | When the latest run was created and its current status. |

The dashboard doesn't show the brief, routine instructions, or chats. A new owner can read the brief and routine instructions after a transfer. The previous owner's private chats do not transfer.

## Manage one agent

Open the actions menu in the agent's row:

- **Pause** stops new runs from doing work. If a run is in progress, OpenWork refuses further tool calls while the agent is paused. **Resume** lets the agent run again.
- **Set budget…** sets a monthly limit for this agent.
- **Change access…** gives teams or the whole organization collaborator access to an already-shared agent. Use **Add to their sidebar** to put it in those members' sidebars. People with individual access keep it.
- **Move to another owner…** transfers the agent and its routines. The previous owner loses owner rights but may still have access through a team or organization share. Runs waiting for the previous owner don't start.
- **Archive…** archives the agent and its routines. Waiting runs don't start. Run history is kept.

## Set rules for every agent

Under **For every agent**:

- **Who can share agents**: **Everyone** lets owners and managers share within their roles. **Admins only** also requires them to be admins. Existing access stays in place. An agent whose owner isn't an admin can't be shared for the first time unless the setting changes or an admin becomes its owner.
- **Shared logins**: Off by default. Turning it off removes saved loans. Turning it back on doesn't restore them. See [Whose accounts it uses](/agents/share-an-agent#whose-accounts-it-uses).
- **Rules every agent follows**: Choose **Edit…** to write instructions for runs. Use tool rules to enforce access.
- **Most an agent may spend in a month**: Set a limit that applies to each agent.

Under **Tool rules for every agent**, choose **Add a tool rule…**:

- **Blocked** stops the tool, even after a one-run approval.
- **Ask first** requires approval even if the agent is set to **Allow**.
- **Allow automatically** lets a tool run without asking unless the agent is set to **Ask** or **Block**.

These rules don't cover built-in connections. **Who changed what** shows who made changes and when, without showing briefs or what was sent to a tool.
