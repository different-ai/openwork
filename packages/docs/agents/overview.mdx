<Warning>
Agents are in private alpha. OpenWork does not officially support this feature yet, and how it works may change. To try it, ask your OpenWork contact to turn it on for your organization.
</Warning>

An agent is a named helper for a recurring job. Its brief says what to do and how to report back. Each routine has its own instructions and schedule and runs in OpenWork Cloud. Each run gets the organization's written rules, if any, followed by the agent's brief and the routine's instructions.

For example, Dana Reyes makes **Bug watcher** with a routine called **Check #bugs**. She opens it from **Agents** in the sidebar to see results or ask for changes. Each person has their own conversation with the agent in each workspace. Sharing an agent doesn't share your conversation.

## Who does what

| Who | What |
| --- | --- |
| Member | Creates an agent for a recurring job. |
| **Owner** | Sets the job and tool permissions, approves changes, and manages access when sharing is allowed. |
| **Manager** | Runs and renames the agent. Asks the owner to approve changes to the brief, tools, or routines. Can add or remove collaborators when sharing is allowed. |
| **Collaborator** | Uses the agent, runs it, and asks for changes. |
| Admin | Sets organization rules and budgets. Can pause, transfer, or archive agents. |

## What you need

Sign in to an OpenWork Cloud organization with **Agents** turned on. The person a run acts for must have access to the connected app. If the connection uses a personal account, the run normally uses that person's account unless an owner or manager has lent theirs. See [Connect your own account](/cloud/share-with-your-team/connect-your-own-account).
