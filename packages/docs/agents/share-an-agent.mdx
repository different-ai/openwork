<Warning>
Agents are in private alpha. OpenWork does not officially support this feature yet, and how it works may change. To try it, ask your OpenWork contact to turn it on for your organization.
</Warning>

1. In the OpenWork app, click the agent's name at the top of its chat and choose **Share**.
2. Under **Who has access**, click **Add person** and select a teammate. They start as a **Collaborator**.
3. If you're the owner, you can change their role to **Manager**.

![The Who has access window with Sam Okafor as Manager and Priya Nair as Collaborator](/images/agents/share.png)

Admins can give teams or the whole organization access to an already-shared agent. If it isn't added to your sidebar automatically, look under **Shared with you**. See [Admin controls](/agents/admin-controls).

## Choose a role

| Role | What they can do |
| --- | --- |
| **Owner** | Runs the agent and changes its brief, tool settings, and routines. Approves change requests. Only the owner can add or remove managers. |
| **Manager** | Runs and renames the agent. Can add or remove collaborators when sharing is allowed. Changes to the brief, tool settings, or routines wait for the owner's approval. |
| **Collaborator** | Uses and runs the agent. Asks for changes in the chat. |

If Sam Okafor asks to add a routine, Dana Reyes sees the full change, including its instructions, before choosing **Approve** or **Deny** in the chat. Only Dana can approve it as the owner.

## Who can see results

As the **Share** window explains, people with access can read answers from scheduled runs that take place after they get access. They can't read earlier answers. Scheduled answers can contain information from the owner's accounts. Full run details, chats, and other people's manual runs stay private.

Everyone the agent is shared with can also read [its memory](/agents/memory). Only the owner and managers can edit the notes directly.

## Whose accounts it uses

A manual run normally uses the accounts of the person who started it. A scheduled run normally uses the owner's accounts.

If an admin allows shared logins, open **Settings** and go to **What it can use**. If you're the owner or a manager, look for **Let teammates act through my account** on a connection where you use your own login. Turn it on to lend that login. Runs then use that account on that connection, including when they make changes. Teammates can see whose account it is.

You can always take back a login you lent. The owner can also remove a loan on their agent. A loan ends if the lender is no longer the agent's owner or a manager, or leaves the organization.

## If sharing is limited to admins

With **Admins only**, existing access stays in place. Only admins who also own or manage an agent can change its individual shares. If the owner isn't an admin, the agent can't be shared for the first time unless the setting changes or an admin becomes its owner.
