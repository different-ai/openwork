Agents are in private alpha. OpenWork does not officially support this feature yet, and how it works may change. To try it, ask your OpenWork contact to turn it on for your organization.
</Warning>

An agent keeps notes between runs. Every run reads them. It also keeps a short record of what each routine did the last time it ran for the owner. Only the owner's runs read that record, and only the owner can see it.

![The Memory panel of Bug watcher: a note the owner added, and what its routine did last](/images/agents/memory.png)

Memory is notes for the agent, not rules. If a note conflicts with the organization's rules or the agent's brief, the rules and brief win. Don't put passwords in memory.

## Read or edit the notes

Click the agent's name at the top of its chat to open its panel, then choose **Memory**. Everyone the agent is shared with can read the notes. The owner and managers can choose **Edit** to change them, then **Save**. The owner also sees **What each routine did last**. It is the owner's own progress, so nobody else sees it, and it is cleared if the agent moves to another owner.

A collaborator can say “Remember this” in the chat. The note waits for the owner's approval before it appears in memory.

## What a run can save

A run for the owner can add a note. It also records what it did, for the owner's next run of that routine. A run someone else starts can't change memory. If that run has a note worth keeping, it sends a request to the owner instead.

For example, Dana Reyes owns Bug watcher. Its weekday run can remember which bugs it already reported. If Priya Nair runs it and the agent wants to save a note, Dana gets to decide whether to keep it.
