Give Codex your organization's OpenWork skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
codex mcp add openwork --url https://api.openworklabs.com/mcp/agent
```

In the Codex desktop app, paste the URL in `codex://settings/connections` instead.

</Step>
<Step title="Sign in">

```sh
codex mcp login openwork
```

Sign in to OpenWork in the browser and pick your organization.

</Step>
<Step title="Try it">
Ask: "Which OpenWork organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Install as a plugin">
    The OpenWork Connect plugin adds the same server plus a skill that explains the OpenWork workflow:

```sh
codex plugin marketplace add different-ai/openwork --sparse .agents/plugins --sparse integrations/agent-plugins/openwork-connect
codex plugin add openwork-connect@openwork
codex mcp login openwork
```

  </Accordion>
  <Accordion title="Switch organizations">

```sh
codex mcp logout openwork
codex mcp login openwork
```

  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow OpenWork's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
