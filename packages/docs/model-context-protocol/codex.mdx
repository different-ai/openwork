---

Give Codex your organization's OpenWork skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
codex mcp add openwork --url https://api.openworklabs.com/mcp/agent
```

In the Codex desktop app, paste the URL in `codex://settings/connections` instead.

</Step>
<Step title="Sign in">

```sh
codex mcp login openwork
```

Sign in to OpenWork in the browser and pick your organization.

</Step>
<Step title="Try it">
Ask: "Which OpenWork organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">

```sh
codex mcp logout openwork
codex mcp login openwork
```

  </Accordion>
