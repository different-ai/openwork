---

Give Cursor your organization's OpenWork skills, plugins, and connections.

<Steps>
<Step title="Add the server">
[Add OpenWork to Cursor](cursor://anysphere.cursor-deeplink/mcp/install?name=openwork&config=eyJ1cmwiOiJodHRwczovL2FwaS5vcGVud29ya2xhYnMuY29tL21jcC9hZ2VudCJ9) in one click. In Cursor Web or Cursor Agents, paste this as a remote MCP server instead:

```text
https://api.openworklabs.com/mcp/agent
```

</Step>
<Step title="Sign in">
Start OAuth from Cursor's connection prompt, sign in to OpenWork, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which OpenWork organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `openwork` token, then connect again and pick another organization.
  </Accordion>
  <Accordion title="Support status and OAuth callbacks">
    Setup only: native end-to-end proof is not complete. Cursor Desktop uses the callback `cursor://anysphere.cursor-mcp/oauth/callback`, which OpenWork accepts through an exact allowlist with PKCE S256 enforced. Cursor Web and Agents use HTTPS callbacks. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
