Give Gemini CLI your organization's OpenWork skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
gemini mcp add --transport http openwork https://api.openworklabs.com/mcp/agent
```

</Step>
<Step title="Sign in">
Start `gemini`, run `/mcp auth openwork`, sign in to OpenWork in the browser, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which OpenWork organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Remove the stored `openwork` token, run `/mcp auth openwork` again, and pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow OpenWork's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
