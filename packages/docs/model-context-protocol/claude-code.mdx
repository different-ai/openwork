Give Claude Code your organization's OpenWork skills, plugins, and connections.

<Steps>
<Step title="Add the server">

```sh
claude mcp add --transport http openwork https://api.openworklabs.com/mcp/agent
```

Add `-s user` to make it available in every project.

</Step>
<Step title="Sign in">
Run `/mcp` in Claude Code, select `openwork`, sign in to OpenWork in the browser, and pick your organization.
</Step>
<Step title="Try it">
Ask: "Which OpenWork organization am I connected to?"
</Step>
</Steps>

<AccordionGroup>
  <Accordion title="Switch organizations">
    Run `/mcp`, select `openwork`, and clear or re-authenticate it. The next sign-in lets you pick another organization.
  </Accordion>
  <Accordion title="Support status">
    Setup only: these steps follow OpenWork's OAuth profile, but native end-to-end proof is not complete. See the [MCP Gateway reference](/cloud/run-in-the-cloud/cloud-mcp#reference).
  </Accordion>
</AccordionGroup>
