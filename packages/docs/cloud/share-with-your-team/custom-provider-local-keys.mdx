---
title: "Let each Desktop user bring their own key for a shared custom provider"
description: "Share an endpoint and model list once, then have each Desktop user add their own gateway key."
keywords: ["custom provider", "personal API keys", "Desktop", "environment variables"]
---

Configure one endpoint and model list for the team without collecting users' keys or an upstream admin key.
Use this flow for **OpenWork Desktop**. For server-managed keys in Web or Cloud Automations,
use [per-member credential bindings](/cloud/share-with-your-team/per-member-llm-credentials).

## Before you start

- Have permission to create and edit organization providers, plus the gateway's base URL and model IDs.
- Give each user their own inference key and confirm your policy permits local credential storage.
- Use a custom provider with one credential variable. Choose a name no other provider uses.

## 1. Prepare the provider without a shared key

<Note>
**Remove saved key** requires a deployment with saved-key removal and the
`legacyProviderCredentialRemoval` rollout enabled for you. It is off by default.
If the action is absent or locked, ask your OpenWork administrator about availability
before continuing with a provider that has a saved key. Don't delete the provider to clear it.
You can still create a new provider without a key on earlier versions.
</Note>

**Administrator, in OpenWork Cloud:**

1. Select the organization, then open **AI Gateway → AI Providers → Legacy Providers**.
2. Open the existing custom provider, or [create a custom provider](/cloud/share-with-your-team/custom-llm-provider#advanced-raw-json-config)
   with its endpoint and models. Leave **API key / credential** blank for a new provider.
3. Open **Advanced: edit as JSON** and find the top-level `env` list, for example:

   ```json
   "env": ["TEAM_GATEWAY_API_KEY"]
   ```

   Use the name actually declared in your provider, not necessarily this example.
   Coordinate any rename with existing users before changing it.
4. Save and check **Provider configuration** on the detail page as an authorized editor.
   Confirm **Credential missing**. A blank edit field doesn't clear a saved key. If it says **Credential saved**:
   1. Select **Remove saved key** next to the credential status and confirm. The provider, its models and access grants stay in place; users don't need to pick the model again.
   2. Confirm **Credential missing**, then tell existing users to run **Sync now**. Sync removes the old shared value only if it still matches the previously synced key; a different personal value is kept.
   3. If the old key was real, revoke or rotate it upstream. Removing the saved copy doesn't revoke it, and offline or signed-out devices keep their copy until they sync.
5. Under **Who can use it**, grant only the intended people or teams access and save.
6. Send users the provider name, a model to select, and the exact variable name from `env`.

Keep the default `shared` mode with no organization key. If an existing provider uses
`per_member`, use its [member-binding flow](/cloud/share-with-your-team/per-member-llm-credentials#member-flow) instead.

<Warning>
Never add an organization key to this provider: sync can distribute it and overwrite users' local values.
</Warning>

## 2. Add your own key in Desktop

**Each user, on each computer:**

1. Sign in to the organization that shared the provider.
2. Open **Settings → Environment → Add variable**.
3. Enter the exact variable name your administrator supplied, including capitalization.
   If it already serves another provider, ask your administrator before replacing it.
4. Paste your own inference key as the value. Keep it hidden and out of chat messages.
5. Select **Save**, finish active work, then **Apply** and confirm the restart/apply prompt.
6. Open **Settings → AI Providers → Sync now**.
7. Select the shared model in a conversation and send a short, non-sensitive prompt.

## If the model is missing

- Check the selected organization and ask your administrator to confirm your provider grant.
- Match the variable name to `env`, complete Apply, then use **Sync now**.
- Have your administrator check for an inherited variable overriding the saved value, without printing it.

For other credential options, see [Provider support](/ai-gateway/provider-support).
