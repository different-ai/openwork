sidebarTitle: "Overview"
description: "Create, find, and share interactive artifacts in OpenWork."
---

Open **Artifacts** in the sidebar to find the interactive views you've built or that others have shared with you. An artifact can be a dashboard, tracker, form, calculator, or other view you can come back to.

To create one, ask OpenWork in chat for the view you want. For example, ask for a tracker that lists your team's open issues. OpenWork builds the artifact and opens it beside the chat. Find it again under **Yours** in Artifacts. You can also pin it or share it with teammates.

An artifact can use live data from the viewer's own connected services. Each artifact has its own MCP server, so you can also open it in a compatible MCP client. [How artifacts work with MCP](/cloud/run-in-the-cloud/cloud-mcp)

If you are developing an integration with its own interactive interface, see [Build an MCP App](/dashboards/build-an-mcp-app).
