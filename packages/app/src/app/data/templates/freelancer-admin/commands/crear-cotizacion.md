---
name: crear-cotizacion
description: Crear cotización profesional para un cliente
---

Necesito crear una cotización para un cliente.

Pregúntame:
1. ¿Qué servicio(s) vas a cotizar?
2. ¿Para qué cliente?
3. ¿Precio por servicio o por proyecto?
4. ¿En qué país? (para moneda e impuestos)
5. ¿Tiempo de entrega estimado?

Genero una cotización profesional con:
- Desglose de servicios con precios
- Impuestos aplicables
- Condiciones de pago (anticipo, plazos)
- Vigencia de la cotización
- Términos y condiciones básicos
- Lista para enviar al cliente
