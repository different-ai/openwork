name: crear-kb-article
description: Crear un artículo de base de conocimiento a partir de un ticket resuelto
---

Crea un artículo de base de conocimiento.

Pregúntame:
1. ¿Qué problema resuelve? (o pégame el ticket resuelto)
2. ¿Tipo de artículo? (how-to, troubleshooting, FAQ)
3. ¿A qué producto/versión aplica?
4. ¿Quién es la audiencia? (usuario final, admin, desarrollador)

Genero un artículo completo con:
- Título desde la perspectiva del usuario
- Síntoma/problema descrito como lo experimenta el usuario
- Causa explicada en lenguaje simple
- Solución paso a paso (con indicaciones visuales de dónde hacer clic)
- Verificación de que el problema se resolvió
- Qué hacer si persiste
- Tags y categoría sugeridos

Sigo los estándares del skill de base de conocimiento. El artículo queda listo para publicar.
