name: preparar-documentos
description: Generar borrador de documento para trámite migratorio
---

Necesito preparar un documento para un trámite migratorio.

Pregúntame:
1. ¿Qué tipo de documento? (carta de invitación, carta de empleo, declaración jurada, carta de motivos)
2. ¿Para qué trámite o visa?
3. ¿Ante qué autoridad? (consulado, embajada, USCIS, INM)
4. ¿Datos del solicitante?

Genero un borrador profesional con:
- Formato correcto para la autoridad correspondiente
- Todos los datos requeridos
- Lenguaje formal y preciso
- Versión bilingüe si es necesario

⚠️ Este es un borrador. Debe ser revisado por un abogado migratorio antes de presentarse.
