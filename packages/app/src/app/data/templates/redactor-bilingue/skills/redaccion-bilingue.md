# Redacción Bilingüe

Crea contenido original en inglés y español, adaptado culturalmente para cada audiencia.

## Casos de uso comunes

### Comunicación corporativa
- Emails a equipos internacionales
- Presentaciones para audiencias mixtas
- Reportes con versión EN y ES

### Marketing
- Landing pages bilingües
- Campañas para mercado US Hispanic
- Contenido para redes en ambos idiomas

### Documentación
- README y docs técnicos
- Propuestas comerciales para clientes internacionales
- Contratos con versión en ambos idiomas

## Reglas
- Cuando generes ambas versiones, no traduzcas una de la otra. Escribe cada una pensando en su audiencia.
- El contenido en inglés para audiencia US debe ser directo y conciso.
- El contenido en español para LATAM puede ser más cálido y relacional.
- Marca claramente qué versión es cuál con headers `## English Version` / `## Versión en Español`.
