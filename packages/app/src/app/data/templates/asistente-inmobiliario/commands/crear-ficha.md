name: crear-ficha
description: Crear ficha técnica de propiedad para publicación
---

Necesito crear una ficha de propiedad.

Pregúntame:
1. ¿Qué tipo de propiedad? (casa, departamento, oficina, local, terreno)
2. ¿Venta o renta?
3. ¿Ubicación? (colonia, ciudad, país)
4. ¿Características? (m², recámaras, baños, estacionamiento, amenidades)
5. ¿Precio?

Genero una ficha profesional con:
- Descripción atractiva para portales inmobiliarios
- Características organizadas con iconos
- Puntos de interés cercanos
- Condiciones (depósito, mantenimiento, disponibilidad)
- Lista para copiar y publicar
