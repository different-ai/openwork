---

Crea una ficha de producto para mi tienda en línea.

Pregúntame:
1. ¿Qué producto es? (nombre, marca, tipo)
2. ¿Cuál es el precio? (con o sin IVA)
3. ¿Tienes fotos o debo sugerir el tipo de fotos necesarias?
4. ¿Qué plataforma usas? (Shopify, WooCommerce, Mercado Libre, otra)

Genera:
- SKU sugerido
- Nombre optimizado para SEO
- Descripción corta (para listados)
- Descripción larga (con beneficios, características, especificaciones)
- Categoría sugerida
- Tags/etiquetas para búsqueda
- Meta title y meta description
- Sugerencias de productos relacionados (cross-sell)

Sigue los estándares del skill de gestión de catálogo.
