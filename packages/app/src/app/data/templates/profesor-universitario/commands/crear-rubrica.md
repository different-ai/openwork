---
name: crear-rubrica
description: Crear rúbrica de evaluación para una actividad
---

Necesito una rúbrica para evaluar una actividad.

Pregúntame:
1. ¿Qué actividad? (ensayo, presentación, proyecto, práctica)
2. ¿Qué criterios son importantes?
3. ¿Escala de calificación? (1-10, 1-5, letras)
4. ¿Cuántos niveles de desempeño?

Genero una rúbrica con:
- Criterios claros y observables
- Descriptores específicos para cada nivel
- Puntaje por criterio
- Total y equivalencia a calificación
- Lista para usar o adaptar
