---
name: investigar-tema
description: Investigar un tema a profundidad con fuentes verificables
---

Necesito que investigues a profundidad el siguiente tema.

Pregúntame:
1. ¿Cuál es el tema o pregunta específica?
2. ¿Para qué contexto? (decisión de negocio, artículo, presentación, tarea académica)
3. ¿Hay algún país o región de enfoque?
4. ¿Qué nivel de profundidad? (resumen rápido, reporte completo, análisis exhaustivo)

Luego:
- Busca en múltiples fuentes web
- Verifica la información cruzando fuentes
- Genera un reporte estructurado con resumen ejecutivo, hallazgos clave, datos relevantes y todas las fuentes con URLs
- Si encuentras datos contradictorios, señálalos
