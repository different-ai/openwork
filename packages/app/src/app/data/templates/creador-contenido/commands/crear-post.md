---

Ayúdame a crear un post para redes sociales.

Pregúntame:
1. ¿Para qué plataforma? (X/Twitter, LinkedIn, Instagram, todas)
2. ¿Cuál es el tema o mensaje principal?
3. ¿Qué tono? (profesional, casual, inspirador, provocador)
4. ¿Hay un CTA? (link, comentar, compartir, comprar)

Genera:
- El post listo para copiar y pegar, adaptado a la plataforma
- Hashtags relevantes
- Sugerencia de horario de publicación (zona horaria LATAM)
- Sugerencia de imagen o visual
- Si pedí "todas", genera una versión para cada plataforma
