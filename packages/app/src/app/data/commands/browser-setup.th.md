---

ช่วยผู้ใช้ตั้งค่า **การควบคุมเว็บเบราว์เซอร์แบบอัตโนมัติ** ใน OpenWork

สิ่งสำคัญ:
- อย่าเรียกใช้เครื่องมือในข้อความแรก ให้แสดงขั้นตอนการตั้งค่าเท่านั้น
- สมมติว่าเครื่องมือควบคุมเบราว์เซอร์อาจยังไม่พร้อมใช้งาน แนะนำผู้ใช้ให้เปิดใช้งาน

ถามคำถามสั้นๆ 1-2 ข้อก่อน:
1) คุณใช้ OpenWork แบบไหนอยู่? (Desktop app หรือ Web app)
2) มี Google Chrome ติดตั้งในเครื่องนี้หรือไม่?

จากนั้น:
1) อธิบายวิธีการ 2 แบบที่รองรับ:
   - **OpenCode Browser (แนะนำ)** ⭐: ติดตั้ง/เปิดใช้งาน browser plugin/extension และเชื่อมต่อ ใช้งานง่าย ไม่ต้องเขียนโค้ด
   - **Playwright (ทางเลือกรอง)**: รันผ่านโค้ดโดยใช้ Node + Playwright library ต้องติดตั้ง Node และ npm packages
2) ถ้าต้องการใช้ OpenCode Browser:
   - ตรวจสอบในแท็บ Plugins ใน OpenWork
   - มองหาสถานะ "เชื่อมต่อแล้ว"
   - ถ้ายังไม่ได้ติดตั้ง ให้ติดตั้ง OpenCode Browser extension จาก Chrome Web Store
   - กรุณายืนยันเมื่อตั้งค่าเสร็จสิ้น
3) เมื่อยืนยันว่าตั้งค่าเสร็จแล้ว เสนองานแรกง่ายๆ: ลองเปิดเว็บเพจและอ่านชื่อเรื่อง

ให้คำแนะนำสั้นๆ กระชับ และลงมือทำได้จริง
